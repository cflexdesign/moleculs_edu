# Обучение Молекуле для бизнеса

HTML-обучение на русском языке: 27 коротких заданий, справочник моделей и ролей, маршруты продаж и шести отделов.

## Открыть курс

[Открыть базу знаний на сайте Молекулы](https://moleculai.ru/knowledge-base)

[Статическая версия с отметками прогресса](https://cflexdesign.github.io/moleculs_edu/)

Скачайте или клонируйте репозиторий и откройте `outputs/knowledge-base/index.html` в браузере. Сохраняйте расположение папок `knowledge-base`, `assets`, `media` и остальных файлов внутри `outputs`.

Описание текущей редакции находится в [README курса](outputs/knowledge-base/README.md). Предыдущий отдельный курс из 18 уроков доступен в `outputs/molecula-academy.html`.

Редакция по документу изменений: длинные уроки разделены, повторяющиеся инструкции объединены, старые адреса перенаправлены. Закрытые исходники и служебные сведения исключены из публичных материалов.

## Обновления

Проверенные изменения базы публикуются прямо в CMS русского сайта. Скрипт и порядок публикации: [scripts/README.md](scripts/README.md). Запросы, карточки, изображения и видео преобразуются в родные компоненты сайта; вопросы для самопроверки имеют раскрываемый разбор ответа. Отметки прогресса и интерактивные тесты остаются в статической версии.

Рабочие файлы из `work/`, ключи доступа, резервные копии CMS, ZIP-архив и дублирующая автономная HTML-сборка не включаются в Git.

Репозиторий: https://github.com/cflexdesign/moleculs_edu. Ветка: `main`. Codex должен отправлять завершённые изменения после проверки, как описано в `AGENTS.md`. Для отправки нужен действующий вход в GitHub на этом компьютере.

GitHub Pages публикует корень ветки `main` и обновляет сайт после отправки коммитов. Корневой `index.html` открывает основную страницу курса; `.nojekyll` сохраняет статические файлы без обработки Jekyll.
