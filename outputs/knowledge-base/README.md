# База знаний Молекулы

Основная версия находится [на сайте Молекулы](https://moleculai.ru/knowledge-base). Завершённые изменения публикуются в русскую CMS после проверки; GitHub хранит статическое зеркало.

Начните с index.html и руководства 003.html «Первый чат». Оно показывает поле сообщения, выбор модели, первый запрос и одну правку. Для первой пробы свои файлы не нужны.

## Пользовательский маршрут

Разделы: начало работы, текст, изображения, видео, аватары, аудио, роли, проекты и файлы. Отдельные руководства помогают учиться по конспекту, писать сообщения, готовить резюме и переводы, собирать содержание презентации, создавать карточки товара и пользоваться стилями.

В 33 подробных руководствах есть объяснение инструмента, короткая последовательность действий, три заполненных запроса, образцы результатов, разбор и следующий шаг. Первый пример открыт; остальные можно раскрыть по необходимости. Добавлены настоящие снимки нового чата, выбора модели, стилей фото, настроек видео и музыкальных полей.

В каталогах 62 модели и 41 роль. Каждая карточка объясняет назначение, путь в кабинете, исходные материалы и три сценария. Названия сверены с меню Молекулы. Учебные сценарии не являются сравнительным тестом всех версий.

Текстовые образцы и описания ожидаемых результатов написаны для обучения. Сохранённые генерации подписаны отдельно: их не выдают за новые результаты соседнего запроса. Новые генерации не запускались.

## Практика и прежние адреса

Девять бизнес-модулей и 27 заданий сохранены как отдельный маршрут в program.html. К заданиям добавлены другие ситуации для повторения способа работы. Исходные запросы, вопросы самопроверки и идентификаторы отметок сохранены. В статической версии можно переносить отметки через раскрываемый блок в программе.

В базе 108 содержательных HTML-страниц и 39 перенаправлений. Старые адреса и якоря моделей и ролей сохранены. В CMS модели и роли опубликованы отдельными страницами; отношения существующих страниц остаются прежними.

CMS поддерживает копирование запросов, карточки, медиа и раскрываемые пояснения. Переносимый прогресс и интерактивные тесты относятся к статической версии. В CMS самопроверка представлена вопросом и раскрываемым разбором.

Отдельные sales-academy, team-academy и старый курс из 18 уроков этой переработкой не изменяются и не импортируются в CMS.

## Сборка и проверка

Сохраняйте папки knowledge-base, assets и media рядом. Пользовательский слой собирается scripts/build_user_guides.py; собственные учебные тексты находятся в scripts/user_guide_content.py, исходные карточки в scripts/user-guide-catalog.json.

Проверка scripts/verify_user_guides.py охватывает местные ссылки, якоря, копирование, три примера в каждом руководстве и профиле, сохранение запросов 27 заданий и правильный инструмент каждого запроса при экспорте. Для проверки CMS нужен локальный снимок её структуры. Служебные отчёты, источники исследования и ключи остаются в исключённой из Git папке work.

Порядок публикации описан в scripts/README.md.
