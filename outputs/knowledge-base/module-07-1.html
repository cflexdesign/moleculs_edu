Оживить изображение товара, сохранив его конструкцию

У магазина «Лист» есть хороший кадр органайзера, но для страницы товара или короткого поста нужна небольшая видеовставка.

Нужно: аккаунт и доступный баланс. Все факты есть в запросе; исходное фото скачайте ниже.

Получится: один короткий план для проверки.

Что сделать

  1. Откройте «Новый чат» → «Видео» и выберите Kling 2.1 Standard.
  2. Скачайте исходник ниже и прикрепите его к запросу.
  3. Скопируйте запрос целиком и получите один вариант.
  4. Сравните его с примером и тремя проверками. Исправьте конкретное расхождение.
  5. Сохраните принятую версию и отметьте выполнение.
Скачать исходное фото

Готовые материалы ниже можно разобрать без нового запуска.

Открыть кабинет Молекулы

Запрос

Камера очень медленно приближается к органайзеру с прикреплённого фото. Предмет неподвижен и целиком виден. Сохранить серую ткань, три отделения, две перегородки, швы и отсутствие ручек. Ровный свет. Один план без склеек, короткая пауза в конце. Без речи и надписей.

Пример и разбор

В первом примере товар обрезается при приближении. Во втором наезд мягче, но к концу предмет всё равно подрезан. Оба варианта требуют правки для общего плана; отдельный крупный план оценивают по другой задаче.

Откройте «Видео» и выберите модель с входным фото. Сохранённый пример ниже сделан Kling 2.1 Standard. Для новой модели используйте собственный результат и ту же проверку. Перед запуском посмотрите цену на экране.

Три проверки

Ещё два примера этого способа работы

Начните с короткого плана. Готовая фотография задаёт внешний вид, а запрос описывает движение.

Образцы ниже подготовлены для обучения; это дополнительные ситуации, а не новые запуски модели.

Пример 2. Оживить иллюстрацию

Для этого примера откройте «Видео».

Запрос для этого примера

Оживи приложенную иллюстрацию парка. Камера неподвижна. Листья на дереве слегка колышутся, на поверхности маленькой лужи появляется мягкая рябь. Ребёнок и кот остаются на месте, их внешность и пропорции сохраняются. Спокойная сцена, один план.

Как может выглядеть результат

Ожидаются два небольших движения окружения при неподвижных героях. Не должно появляться новое действие персонажей.

Что здесь полезно

Маленькое движение помогает сохранить стиль иллюстрации и делает её живой без сложной сцены.

Следующее сообщение

Рябь слишком заметная. Уменьши её, дерево и персонажей сохрани.
Пример 3. Портрет для короткого вступления

Для этого примера откройте «Видео».

Запрос для этого примера

Оживи приложенный портрет вымышленной ведущей. Неподвижная камера, естественное моргание, лёгкий кивок в конце. Лицо, причёска, одежда и фон сохраняются. Спокойное выражение, без речи и крупных жестов. Один непрерывный план.

Как может выглядеть результат

Ожидается немой портретный клип. Он не является произнесённым приветствием и не подтверждает синхронизацию губ.

Что здесь полезно

Тихая проба помогает проверить лицо и движения до более сложной задачи с речью.

Следующее сообщение

Кивок выглядит резким. Уменьши его, оставь естественное моргание.
Подробное руководство

Проверьте себя

Какое решение соответствует назначению материала и не требует новой генерации?

К концу клипа товар обрезан. Для отдельного крупного плана этот участок может подойти.

Решение опирается на задачу: показать товар целиком. Материал с дефектом общего плана иногда пригоден для другой роли, но это требует отдельной приемки.
