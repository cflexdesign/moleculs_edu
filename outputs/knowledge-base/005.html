Роли: выбрать по документу

Роль помогает оформить ваш документ

Роль — готовая инструкция о способе работы. Она не знает товар, клиента и согласованные условия. Факты передайте в запросе сами. Для первого задания роль необязательна: чат по умолчанию открывается без неё.

Роли работают внутри модели МОЛЕКУЛА, которая в списке моделей называется «Молли 1.0». В разделе «Роли» есть поиск и семь разделов, включая «Рекомендуем». Можно выбрать роль прямо рядом с полем ввода.

  1. Выберите нужный документ: ответ клиенту, план публикаций, таблицу резюме или смету.
  2. Откройте «Роли», найдите точное имя из карточки и нажмите «Начать чат с ролью».
  3. Скопируйте заполненный запрос. Замените три факта своими проверенными сведениями; неизвестное так и назовите.
  4. Проверьте документ: факты сохранены, обещания подтверждены, нужный формат соблюдён.

Например, «Копирайтер» помогает написать ответ клиенту, «HR-консультант» — связать резюме с критериями вакансии, «Бизнес-аналитик» — оформить расчёт. Роль не принимает решение о найме, не подтверждает причины изменения показателей и не создаёт готовый ролик по одному сценарию.

Сначала попробуйте один запрос на фактах своей компании. Если ответ ошибся, назовите конкретную правку. Когда цена, срок или свойство неизвестны, попросите вопрос для уточнения. Не дописывайте факты ради красивого текста.

В «Рекомендуем» находятся Копирайтер и SMM-менеджер. Четыре личные роли сохранены отдельно от делового пути. Для задачи компании выбирайте документ, по которому сможете проверить результат.
