LIST-LEADS-01 — учебные обращения магазина «Лист»
Все сведения вымышлены. Это авторский набор для упражнения.

Периоды A и B — два полных периода по 7 дней. Правило учёта одинаковое.
Один ID означает одну уникальную заявку. У заявки может быть не более одного оплаченного заказа в её периоде.
«Да» — оплаченный заказ есть; «Нет» — оплаченного заказа нет; «—» — итог пока не внесён, его нельзя считать ни «Да», ни «Нет».
Конверсия = число заявок с оплаченным заказом / число уникальных заявок × 100%.
Полностью совпадающие записи одного ID считаем техническим дублем: в рабочей копии оставляем первую, в журнале указываем обе строки. Если записи одного ID противоречат друг другу, требуется уточнение.
Номер строки служит для проверки исходника и не является отдельной заявкой.
